# GameFinder

Upload the CONTENTS of this folder to your GitHub repository.

Render settings:
- Service: Web Service
- Language: Node
- Build: npm install
- Start: npm start
- Root directory: leave empty
- Instance: Free for an initial trial
- Health check: /api/status

Optional secret: GEMINI_API_KEY, set in Render environment variables only.
The RENDER_EXTERNAL_HOSTNAME variable is supplied by Render.

This package contains no API keys or .env files. Free hosting may sleep when idle. Device and voice support depend on the browser. Favorites remain on each device.
